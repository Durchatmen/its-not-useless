---
## 一、前端开发

| 类别 | 选型 | 用途 |
|------|------|------|
| 框架 | **Vue 3 + TypeScript** | 响应式 Web 前端 |
| 构建 | **Vite** | 开发热更新、打包 |
| 路由 | **Vue Router** | 页面路由与权限守卫 |
| 状态 | **Pinia** | 登录态、就诊人、会话上下文 |
| UI | **Element Plus / Ant Design Vue**（二选一） | PC 端为主，兼容移动端 |
| HTTP | **Axios** | 请求拦截、Token 刷新、`X-Request-Id` |
| 地图 | **高德地图 JS API** | 院外导航、院内地图展示 |
| 通知 | **Notification API** | 叫号、报告、用药提醒 |
| 日历 | **ics** | 用药提醒导出日历 |
| 样式 | **Sass / Less + PostCSS** | 响应式、大字模式、高对比度 |

## 二、后端开发

| 类别     | 选型                           | 用途                           |
| -------- | ------------------------------ | ------------------------------ |
| 语言     | **Python 3.11+**               | 与 AI 生态一致                 |
| 框架     | **FastAPI**                    | 异步接口、OpenAPI              |
| 服务器   | **Uvicorn**（开发 `--reload`） | 本地启动                       |
| 校验     | **Pydantic v2**                | 请求/响应模型                  |
| ORM      | **SQLAlchemy 2.0**             | MySQL 操作                     |
| 认证     | **PyJWT + Passlib[bcrypt]**    | JWT、密码加密                  |
| 异步任务 | **Celery + Redis**             | AI 生成、报告分析、提醒推送    |
| 文件上传 | **python-multipart**           | 文件上传                       |
| 外部调用 | **httpx**                      | 调大模型、地图、支付、HIS 接口 |
| 流式输出 | **SSE / WebSocket**            | AI 对话流式返回                |

> 已移除：Alembic 数据库迁移。

## 三、AI 与 RAG 开发

| 类别       | 选型                                | 用途                                      |
| ---------- | ----------------------------------- | ----------------------------------------- |
| Agent 编排 | **LangGraph**                       | 预诊、分诊、报告、用药等 Agent            |
| 大模型     | **Qwen3.5**                         | 主模型：预诊分诊、报告/病历解读、医保问答 |
| 备选模型   | **Qwen2.5**                         | 按需切换或对比测试                        |
| 模型服务   | **Ollama / vLLM**                   | 本地跑 Qwen3.5 / Qwen2.5，支持流式        |
| Embedding  | **BGE-M3**                          | 向量化，中英文长文本                      |
| 重排序     | **BGE-reranker-v2-m3**              | RAG 精排，提升召回质量                    |
| 稀疏检索   | **rank_bm25 / Milvus 稀疏向量**     | 与稠密向量混合检索                        |
| 向量库     | **Milvus**（Docker 或 Milvus Lite） | 六大知识库                                |
| RAG 框架   | **LangChain / LlamaIndex**（可选）  | 文档加载、切块、检索链                    |
| 文档解析   | **PyMuPDF / Unstructured**          | PDF、Word、扫描件解析                     |
| OCR        | **PaddleOCR**                       | 报告、药盒、化验单文字识别                |
| 观测       | **Langfuse**（本地可选）            | 追踪 LLM 调用与提示词                     |

> 已移除：ASR、Qwen-VL。

## 四、数据与中间件（开发环境）

| 类别       | 选型                           | 用途                         |
| ---------- | ------------------------------ | ---------------------------- |
| 关系库     | **MySQL 8.0**（Docker）        | 用户、挂号、支付、病历、处方 |
| 缓存       | **Redis 7**（Docker）          | Token、会话、队列、锁        |
| 向量库     | **Milvus 2.4+**（Docker）      | 知识库向量检索               |
| 对象存储   | **本地文件系统 / MinIO**       | 文件存储                     |
| 会话持久化 | **SQLite / Redis**（开发轻量） | LangGraph 多轮会话           |
| 消息队列   | **Redis**（开发够用）          | Celery broker、简单事件      |
