# 医学检验常见异常指标解读知识库

## 文档说明

### 用途定位

本文档用于**检验报告解读场景**，作为结构化知识库供 AI 辅助解读或医学/健康管理专业人员参考。覆盖血常规、肝功能、肾功能、血脂血糖、电解质、心肌标志物、凝血与纤溶、甲状腺功能、尿常规、免疫与炎症等十类检验项目，收录日常报告中约 100 项核心指标。

### 字段约定

每条指标统一采用以下字段结构，便于机器解析与人工检索：

| 字段 | 含义 |
|------|------|
| `name` | 指标中文名 |
| `abbr` | 常见缩写 |
| `unit` | 常见单位（不同方法学可不同） |
| `ref` | 成人通用参考区间，仅作兜底口径 |
| `mechanism` | 指标产生的生理/病理机制 |
| `↑ causes` | 升高（异常）的常见原因 |
| `↓ causes` | 降低（异常）的常见原因 |
| `combos` | 与本类其他指标组合时的判读逻辑 |
| `suggest` | 异常时的复查/就诊方向 |
| `warn` | 需优先排除的急重症或常见干扰因素 |

### 使用规则（强制约束）

1. **单一指标异常不等于疾病**。参考区间基于约 95% 的健康人群，约 5% 的健康人可能落在区间外；轻度上下浮动若无临床症状，不必过度紧张。
2. **以报告单标注的参考区间为准**。不同实验室、仪器、试剂与年龄性别的参考区间存在差异，本文档参考区间仅为缺失值兜底，不得覆盖报告单区间。
3. **区分生理性与病理性**。运动、饮酒、应激、月经、妊娠、采血不畅、标本放置过久、药物均可能影响结果，解读前必须核对受检者状态。
4. **判读必须回到临床场景**。需结合症状体征、病史用药史、其他检查与连续复查结果，不能由指标倒推诊断。
5. **本文档不构成诊疗依据**。急性胸痛、呼吸困难、意识障碍、高热伴心率显著增快、明显黄疸、肉眼血尿等急症场景，应直接引导急诊就医而非继续指标解读。

## 一、血常规

### 1.1 白细胞计数 WBC

| 字段 | 内容 |
|------|------|
| `ref` | 成人 (3.5~9.5)×10⁹/L；0~19 岁 (4.0~10.0)×10⁹/L |
| `mechanism` | 外周血中中性粒细胞、淋巴细胞、单核细胞、嗜酸性粒细胞、嗜碱性粒细胞的总数，反映免疫与炎症激活状态；总数主要受中性粒细胞与淋巴细胞数量影响 |
| `↑ causes` | 急性化脓性细菌感染、严重组织损伤或出血、烧伤创伤、中毒（尿毒症、糖尿病酮症酸中毒）、某些白血病/淋巴瘤、药物反应 |
| `↓ causes` | 部分病毒感染（流感、肝炎、风疹等）、伤寒/副伤寒等革兰阴性菌感染、药物（磺胺、解热镇痛药、部分抗生素、抗甲状腺药、抗肿瘤药）、放射线与苯类化学品、再生障碍性贫血、脾功能亢进 |
| `combos` | 中性粒比例显著升高→细菌感染可能性大；淋巴比例升高→病毒或某些慢性感染；同时伴贫血与血小板减少→需警惕血液系统疾病 |
| `suggest` | 偏离较大或伴发热时查感染/血液科；结合 CRP、PCT 与分类计数 |
| `warn` | 妊娠、剧烈运动、饮酒、情绪应激、月经前后可生理性升高；白细胞极度升高伴症状需排除白血病 |

### 1.2 中性粒细胞 NEUT / NEUT%

| 字段 | 内容 |
|------|------|
| `ref` | 绝对值 (1.8~6.3)×10⁹/L；百分数 40%~75% |
| `mechanism` | 骨髓生成的吞噬性粒细胞，是急性细菌性炎症的第一线反应细胞 |
| `↑ causes` | 急性化脓性感染、急性出血/溶血、手术后、糖尿病酮症酸中毒、尿毒症、急性中毒、骨髓增殖性肿瘤 |
| `↓ causes` | 伤寒/副伤寒等感染、药物与放射损害、再生障碍性贫血、自身免疫性疾病、脾功能亢进 |
| `combos` | 升高伴 WBC 升高→急性化脓性感染；降低伴发热→警惕粒细胞缺乏与重症感染风险 |
| `suggest` | 结合 WBC、CRP 与临床症状，必要时复查并做血培养 |
| `warn` | 严重感染或脓毒症时可不升反降，需结合临床 |

### 1.3 淋巴细胞 LYM / LYM%

| 字段 | 内容 |
|------|------|
| `ref` | 绝对值 (1.1~3.2)×10⁹/L；百分数 20%~50%|
| `mechanism` | 适应性免疫核心细胞，含 T/B/NK 细胞，参与病毒清除与体液免疫 |
| `↑ causes` | 淋巴细胞性白血病、百日咳、传染性单核细胞增多症、水痘、麻疹、结核、病毒感染恢复期 |
| `↓ causes` | 免疫缺陷病、丙种球蛋白缺乏、应用糖皮质激素/放射、HIV 感染、急性应激 |
| `combos` | 淋巴比例明显升高而中性粒相对降低→病毒或某些慢性感染倾向；绝对值与比例需结合判断 |
| `suggest` | 持续异常查感染科或血液科，必要时做淋巴细胞亚群与病毒学检测 |

### 1.4 嗜酸性粒细胞 EOS / EOS%

| 字段 | 内容 |
|------|------|
| `ref` | 绝对值 (0.02~0.52)×10⁹/L；百分数 0.4%~8.0%|
| `mechanism` | 参与过敏反应与抗寄生虫免疫 |
| `↑ causes` | 过敏性疾病、寄生虫感染、某些皮肤病、嗜酸性粒细胞增多综合征、药物反应、恢复期 |
| `↓ causes` | 伤寒/副伤寒、应用糖皮质激素或促肾上腺皮质激素、急性应激 |
| `combos` | 升高伴 IgE/过敏史→过敏；伴旅行史→寄生虫；显著升高需排查血液系统增殖性疾病 |
| `suggest` | 结合过敏史、用药史、寄生虫暴露史，必要时查血清 IgE 与寄生虫检测 |

### 1.5 单核细胞 MONO / MONO%

| 字段 | 内容 |
|------|------|
| `ref` | 绝对值 (0.10~0.60)×10⁹/L；百分数 3.0%~10.0% |
| `mechanism` | 吞噬抗原后递呈信息的巨噬细胞前体 |
| `↑ causes` | 亚急性细菌性心内膜炎、伤寒、疟疾、黑热病、活动性结核、单核细胞性白血病、急性感染恢复期 |
| `↓ causes` | 再生障碍性贫血、肿瘤浸润骨髓、其他血细胞增多时的相对性减少 |
| `suggest` | 结合发热病程与感染灶排查，必要时血液科评估 |

### 1.6 红细胞计数 RBC

| 字段 | 内容 |
|------|------|
| `ref` | 男 (4.3~5.8)×10¹²/L；女 (3.8~5.1)×10¹²/L |
| `mechanism` | 携氧载体，同时运输 CO₂ 并参与酸碱调节 |
| `↑ causes` | 相对性（呕吐腹泻、烧伤、出汗、脱水致血液浓缩）；绝对性（高原、慢性缺氧、慢性肺心病、发绀型先心病）；真性红细胞增多症、肾癌等 |
| `↓ causes` | 各类贫血：缺铁性、巨幼细胞性、地中海贫血、溶血性、再生障碍性；慢性失血；妊娠期血容量扩张 |
| `combos` | 必须与 HGB、HCT、MCV/MCH/MCHC 组合判读，RBC 不能单独定贫血类型 |
| `suggest` | 降低时查血液科，完善铁代谢、叶酸/B12、网织红细胞与溶血筛查 |

### 1.7 血红蛋白 HGB

| 字段 | 内容 |
|------|------|
| `ref` | 男 130~175 g/L；女 115~150 g/L |
| `mechanism` | 红细胞内携氧蛋白，比 RBC 更能反映贫血程度 |
| `↑ causes` | 慢性心肺疾病缺氧、真性红细胞增多症、高原适应、失水血液浓缩 |
| `↓ causes` | 缺铁（最常见）、叶酸/B12 缺乏、地中海贫血、溶血、急慢性失血、慢性病贫血、妊娠稀释 |
| `combos` | HGB 降幅大于 RBC→缺铁或失血倾向；RBC 降幅大于 HGB→大细胞性贫血倾向 |
| `suggest` | 下降超轻度或伴乏力苍白时就医；结合 MCV 分型，切勿自行补铁 |
| `warn` | 女性妊娠期与月经期、儿童、老年人参考区间不同，不可直接套用成人标准 |

### 1.8 红细胞比容 HCT

| 字段 | 内容 |
|------|------|
| `ref` | 男 0.40~0.50；女 0.35~0.45 |
| `mechanism` | 红细胞在全血中所占容积比例 |
| `↑ causes` | 各类血液浓缩（呕吐腹泻、失血、烧伤、术后）、红细胞增多症、继发性红细胞增多 |
| `↓ causes` | 各种贫血，下降程度因贫血类型不同而不与 RBC 完全一致 |
| `combos` | 与 HGB、RBC 同步升高→浓缩或增多；同步降低→贫血；是计算 MCV 与估算血容量的重要依据 |

### 1.9 红细胞平均体积 MCV / MCH / MCHC / RDW

| 字段 | 内容 |
|------|------|
| `ref` | MCV 82~100 fL（成人）；MCH 27~34 pg；MCHC 316~354 g/L；RDW 11.5%~14.5%（各实验室略有差异） |
| `mechanism` | 反映单个红细胞大小、血红蛋白含量与体积分布宽度，是贫血形态学分型的核心 |
| `↑ causes` | MCV 升高见于叶酸/B12 缺乏（巨幼细胞性）、酒精相关、部分骨髓增生异常；RDW 升高见于缺铁、混合营养缺乏、溶血 |
| `↓ causes` | MCV 降低见于缺铁性贫血、地中海贫血、慢性病贫血；MCH/MCHC 降低提示低色素 |
| `combos` | 小细胞低色素（MCV↓、MCH↓、MCHC↓）→缺铁或缺珠蛋白合成；大细胞（MCV↑）→叶酸/B12 缺乏；RDW 用于鉴别缺铁与地贫 |
| `suggest` | 构成贫血"小细胞/正细胞/大细胞"+"低色素/正色素"分类基础，需与铁代谢、电泳联合 |

### 1.10 血小板计数 PLT

| 字段 | 内容 |
|------|------|
| `ref` | (125~350)×10⁹/L[citation:1] |
| `mechanism` | 通过黏附聚集与释放反应形成白色血栓，参与止血与凝血 |
| `↑ causes` | 急性失血或溶血后反应性增多、缺铁、炎症、脾切除后、原发性血小板增多症、骨髓增殖性疾病、部分恶性肿瘤 |
| `↓ causes` | 生成减少（再生障碍性贫血、急性白血病、骨髓浸润）；破坏过多（免疫性血小板减少症、脾亢）；消耗（DIC、血栓性微血管病）；药物因素 |
| `combos` | 降低伴 WBC/HGB 同时下降→血液系统疾病或骨髓抑制；升高伴缺铁→补铁后多可回落 |
| `suggest` | 异常先查血液科；<50×10⁹/L 需关注出血倾向，避免剧烈活动与抗血小板药自行使用 |
| `warn` | 血小板日内波动可达 6%~10%；EDTA 抗凝标本可能出现假性血小板减少（聚集所致），必要时镜检复核 |

### 1.11 平均血小板体积 MPV

| 字段 | 内容 |
|------|------|
| `ref` | 7~11 fL|
| `mechanism` | 反映血小板生成活跃度，必须与 PLT 联合解读 |
| `↑ causes` | 骨髓纤维化、免疫性血小板减少性紫癜、血栓性疾病或血栓前状态、脾切除、慢性粒细胞白血病 |
| `↓ causes` | 脾功能亢进、化疗后、再生障碍性贫血、巨幼细胞贫血 |
| `combos` | PLT 降低而 MPV 升高→外周破坏为主；PLT 降低而 MPV 降低→生成减少为主 |
| `suggest` | 单独异常意义有限，须结合 PLT 与外周血涂片 |

## 二、肝功能

### 2.1 丙氨酸氨基转移酶 ALT（谷丙转氨酶）

| 字段 | 内容 |
|------|------|
| `ref` | 成人 0~40 U/L（不同实验室可低至 35 U/L 或采用 0~45 U/L） |
| `mechanism` | 主要存在于肝细胞胞浆，肝细胞受损时释放入血，是肝细胞损伤的敏感指标 |
| `↑ causes` | 病毒性肝炎、脂肪肝、药物性或毒物性肝损伤、酒精性肝病、自身免疫性肝炎、休克/缺血、剧烈运动、近期感染 |
| `combos` | 肝细胞损伤型判读：ALT、AST 升高且显著大于 ALP；ALT>AST 多见于急性肝细胞损伤 |
| `suggest` | 复查肝功能排除一过性升高；持续异常查腹部超声、肝炎病毒标志物、用药史与饮酒史 |
| `warn` | 轻度升高（尤其<2 倍上限）可因疲劳、饮酒、感冒等引起，不宜直接归因疾病 |

### 2.2 天门冬氨酸氨基转移酶 AST（谷草转氨酶）

| 字段 | 内容 |
|------|------|
| `ref` | 成人 0~40 U/L |
| `mechanism` | 存在于肝细胞线粒体、心肌、骨骼肌、肾脏等多组织，对肝损伤的特异性弱于 ALT |
| `↑ causes` | 同 ALT；仅 AST 升高而 ALT 正常时需考虑心肌病变、骨骼肌损伤、溶血或运动 |
| `combos` | AST/ALT 比值>1 可见于慢性肝病或肝硬化；比值明显升高可见于酒精性肝病、某些药物性损伤；需结合两者绝对值 |
| `suggest` | 与 ALT、LDH、CK、肌钙蛋白联合，鉴别肝源性与心/肌源性升高 |

### 2.3 AST/ALT 比值

| 字段 | 内容 |
|------|------|
| `ref` | 正常约 0.8 |
| `mechanism` | 比值反映损伤以胞浆（急性）为主还是线粒体与纤维化（慢性/进展性）为主 |
| `↑ causes` | 慢性肝病、肝硬化、酒精性肝病、进展期肝纤维化；比值显著升高需警惕重症或肿瘤 |
| `↓ causes` | 多数急性肝损伤早期比值偏低 |
| `suggest` | 必须建立在两项绝对值可靠的基础上，单独比值无意义 |

### 2.4 碱性磷酸酶 ALP

| 字段 | 内容 |
|------|------|
| `ref` | 成人 35~100 U/L；儿童与青少年因骨骼生长可显著偏高 |
| `mechanism` | 碱性环境下催化磷酸酯水解，血清中主要来自肝与骨 |
| `↑ causes` | 肝源性：胆汁淤积、胆管阻塞、胆结石、原发性胆汁性胆管炎、原发性硬化性胆管炎、药物性胆汁淤积、肝浸润性病变；骨源性：Paget 病、骨软化/佝偻病、骨肿瘤、骨转移；儿童骨骼生长、妊娠、绝经后、药物性肝损伤 |
| `combos` | 胆汁淤积型判读：ALP 升高且显著大于 ALT/AST；ALP 与 GGT 同步升高提示升高源于肝胆系统 |
| `suggest` | 伴 GGT 升高查肝胆外科/消化内科，查腹部超声；儿童需先排除生理性骨骼生长 |
| `warn` | GGT 正常而 ALP 升高更倾向骨源性，需结合骨代谢与影像 |

### 2.5 γ-谷氨酰转移酶 GGT（γ-GT）

| 字段 | 内容 |
|------|------|
| `ref` | 男 10~60 U/L；女 7~45 U/L（各实验室区间有差异，常见为男 11~50 U/L、女 7~32 U/L） |
| `mechanism` | 主要位于肝细胞毛细胆管侧，对胆汁淤积与酒精、药物诱导敏感 |
| `↑ causes` | 酒精性肝损伤、脂肪肝、病毒性肝炎、药物性肝炎、肝硬化、胆道梗阻、胆道感染、胰腺或前列腺肿瘤 |
| `↓ causes` | 通常无独立临床意义 |
| `combos` | 与 ALP 同步升高支持肝胆源性；单独升高而 ALP 正常需结合饮酒与用药史 |
| `suggest` | 戒酒、停用可疑肝毒性药物 2~4 周后复查；持续升高查腹部超声与肝炎标志物 |

### 2.6 总胆红素 TBIL

| 字段 | 内容 |
|------|------|
| `ref` | 3.4~17.1 μmol/L |
| `mechanism` | TBIL = 直接（结合）胆红素 + 间接（非结合）胆红素，反映胆红素代谢全貌与黄疸程度 |
| `↑ causes` | 肝细胞损伤、胆汁淤积或胆道梗阻、溶血性疾病、Gilbert 综合征等先天性代谢异常 |
| `combos` | 以间接升高为主→溶血或遗传代谢异常；以直接升高为主→胆汁淤积或肝胆梗阻；两者均升高→肝细胞性黄疸 |
| `suggest` | 结合直接/间接胆红素、ALT/AST、ALP/GGT 分型；明显黄疸伴腹痛发热需急诊 |
| `warn` | 轻度升高且各项酶正常常见于 Gilbert 综合征，需避免误判为肝病 |

### 2.7 直接胆红素 DBIL / 间接胆红素 IBIL

| 字段 | 内容 |
|------|------|
| `ref` | DBIL 0~6.8 μmol/L；IBIL 由 TBIL 减 DBIL 得出 |
| `mechanism` | DBIL 为经肝脏结合后产物，IBIL 为尚未结合、主要来自衰老红细胞破坏 |
| `↑ causes` | DBIL↑：胆汁淤积、胆道梗阻、肝内胆汁淤积、各类肝细胞损伤；IBIL↑：溶血、Gilbert/Crigler-Najjar 综合征 |
| `combos` | 决定黄疸分型的三联组合：DBIL/TBIL 比值 + 转氨酶 + ALP/GGT |
| `suggest` | 孤立胆红素升高需结合网织红细胞、乳酸脱氢酶、结合珠蛋白与溶血筛查 |

### 2.8 总蛋白 TP / 白蛋白 ALB / 球蛋白 GLO

| 字段 | 内容 |
|------|------|
| `ref` | TP 60~80 g/L；ALB 40~55 g/L；GLO = TP − ALB|
| `mechanism` | 白蛋白完全由肝脏合成，反映肝脏合成储备与营养状态，半衰期约 20 天，变化滞后于急性损伤 |
| `↑ causes` | 球蛋白升高见于慢性肝病、自身免疫病、感染、多发性骨髓瘤等；TP 升高多为球蛋白升高所致 |
| `↓ causes` | 白蛋白降低见于慢性肝病（常提示损伤持续超过 3 周）、肾病综合征、营养不良、蛋白质丢失性肠病、慢性感染 |
| `combos` | 白/球比值倒置（A/G<1）提示慢性肝病或球蛋白异常增殖；需与前白蛋白、PT 联合评估合成功能 |
| `suggest` | 白蛋白下降需排查肝、肾、营养与慢性炎症四类原因 |

### 2.9 前白蛋白 PA

| 字段 | 内容 |
|------|------|
| `ref` | 200~400 mg/L（各实验室不同） |
| `mechanism` | 肝脏合成的短半衰期蛋白（约 2 天），比白蛋白更敏感反映近期肝合成状态与营养 |
| `↑ causes` | 肾病综合征、长期使用糖皮质激素 |
| `↓ causes` | 急性肝损伤、营养不良、炎症（负急性期反应蛋白） |
| `combos` | PA 与 ALB 均低→营养不良或肝合成下降；PA 低而 ALB 尚正常→提示近期或轻度损害 |

### 2.10 凝血酶原时间 PT / INR

| 字段 | 内容 |
|------|------|
| `ref` | PT 11~14 秒；INR 0.8~1.2（未抗凝者） |
| `mechanism` | 外源性凝血途径功能，依赖维生素 K 的凝血因子（II、VII、IX、X）由肝脏合成 |
| `↑ causes` | 严重肝病、维生素 K 缺乏、口服抗凝药、弥散性血管内凝血、胆汁淤积影响吸收 |
| `combos` | PT/INR 延长是严重肝病合成功能受损的灵敏指标，24 小时内即可出现变化 |
| `suggest` | 与 PLT、纤维蛋白原、肝功能组合评估凝血状态；服用华法林者 INR 目标值由医嘱确定 |

## 三、肾功能与尿酸

### 3.1 血肌酐 Cr

| 字段 | 内容 |
|------|------|
| `ref` | 成人 44~133 μmol/L（部分实验室女性 44~97 μmol/L） |
| `mechanism` | 肌肉代谢产物，几乎全部经肾小球滤过排出，是评估肾小球滤过功能的经典指标 |
| `↑ causes` | 急慢性肾衰竭、肾小球肾炎、尿路梗阻；也可见于肌肉发达、剧烈运动、大量进食肉类 |
| `↓ causes` | 肌肉萎缩、营养不良、肌少症、妊娠 |
| `combos` | 与尿素氮同步升高→肾功能下降可能性大；肌酐单独升高需排除肌肉量与饮食因素；需结合 eGFR |
| `suggest` | 异常时查肾内科，查尿常规、泌尿系统超声与 eGFR；不可仅凭一次结果下结论 |
| `warn` | 肌酐上升时肾功能可能已下降较多，它存在"滞后性"，需结合更敏感指标 |

### 3.2 尿素氮 BUN（尿素）

| 字段 | 内容 |
|------|------|
| `ref` | 2.9~7.2 mmol/L（部分实验室 2.9~8.2 mmol/L）|
| `mechanism` | 蛋白质代谢终产物，经肾排泄，同时受蛋白摄入与分解代谢影响 |
| `↑ causes` | 肾功能不全、高蛋白饮食、脱水、消化道出血、发热、高分解状态、尿路梗阻 |
| `↓ causes` | 严重肝病、营养不良、妊娠 |
| `combos` | BUN/Cr 比值升高更倾向肾前性因素（脱水、高分解）；两者同步升高提示肾实质或梗阻 |
| `suggest` | 与肌酐、电解质、尿常规组合判读，避免把饮食性升高误判为肾衰 |

### 3.3 尿酸 UA

| 字段 | 内容 |
|------|------|
| `ref` | 男 208~428 μmol/L；女 155~357 μmol/L（部分实验室 90~360 μmol/L）|
| `mechanism` | 嘌呤代谢终产物，大部分经肾排泄，少量经肠道 |
| `↑ causes` | 高尿酸血症、痛风、肾功能不全、高嘌呤饮食（海鲜、动物内脏、啤酒）、饮酒、肿瘤溶解、代谢综合征、部分药物 |
| `↓ causes` | 使用促排尿酸药物、恶性贫血、肾小管分泌异常 |
| `combos` | 伴肌酐升高→排泄障碍；肌酐正常而 UA 高→多与饮食、代谢、生成过多相关 |
| `suggest` | 持续升高需查肾内科或风湿免疫科，控制饮食、限酒并复查；伴关节红肿热痛及时就诊 |
| `warn` | 单次升高可由进食导致，需空腹复查确认 |

### 3.4 胱抑素 C Cys-C

| 字段 | 内容 |
|------|------|
| `ref` | 0.6~2.5 mg/L（各实验室不同，常见 0.5~1.03 mg/L）|
| `mechanism` | 由有核细胞恒定产生的低分子量蛋白，经肾小球自由滤过并被近曲小管重吸收，浓度取决于 GFR |
| `↑ causes` | 肾小球滤过功能受损，比肌酐更早提示肾功能改变 |
| `↓ causes` | 较少有独立临床意义 |
| `combos` | 与肌酐、eGFR 联合提高早期肾损伤检出率；受年龄、性别、肌肉量影响小 |
| `suggest` | 适合糖尿病、高血压等高危人群的早期筛查 |

### 3.5 估算肾小球滤过率 eGFR

| 字段 | 内容 |
|------|------|
| `ref` | ≥90 mL/min/1.73m² 为正常 |
| `mechanism` | 由年龄、性别、肌酐（部分公式含种族与胱抑素 C）计算得出，评价肾功能的综合指标 |
| `↑ causes` | 妊娠、高蛋白摄入、运动；临床意义有限 |
| `↓ causes` | 肾功能减退：<60 持续 3 个月提示慢性肾脏病；<15 为肾衰竭期 |
| `combos` | 是肾功能"金标准"式指标，需结合尿蛋白、尿沉渣与影像分期 |
| `suggest` | 下降者定期肾内科随访，控制血压血糖，避免肾毒性药物 |

### 3.6 β2-微球蛋白 β2-MG

| 字段 | 内容 |
|------|------|
| `ref` | 0.9~2.2 mg/L|
| `mechanism` | 由淋巴细胞、血小板等产生，经肾小球滤过、肾小管重吸收 |
| `↑ causes` | 肾功能受损、高血压病、糖尿病肾病、淀粉样变性、多发性骨髓瘤、慢性淋巴细胞白血病 |
| `suggest` | 升高需鉴别肾性因素与血液系统增殖性疾病 |

## 四、血糖与血脂

### 4.1 空腹血糖 GLU

| 字段 | 内容 |
|------|------|
| `ref` | 3.9~6.1 mmol/L |
| `mechanism` | 至少 8 小时未进食后的基础血糖，反映基础胰岛素分泌与肝糖输出 |
| `↑ causes` | 糖尿病、应激性高血糖、库欣/甲亢等内分泌疾病、药物（糖皮质激素、部分抗精神病药）、黎明现象 |
| `↓ causes` | 胰岛素或降糖药过量、进食不足、严重肝病、胰岛素瘤、肾上腺皮质功能不全 |
| `combos` | 6.1~6.9 mmol/L 为空腹血糖受损；≥7.0 mmol/L 需警惕糖尿病，需次日复测或结合 OGTT |
| `suggest` | 异常复查并查糖化血红蛋白；低血糖伴症状需即刻补充糖分并就医 |
| `warn` | 单靠一次空腹血糖不能确诊糖尿病，需符合诊断标准并复测 |

### 4.2 糖化血红蛋白 HbA1c

| 字段 | 内容 |
|------|------|
| `ref` | 4%~6%（控制目标由疾病状态决定，一般糖尿病<7%） |
| `mechanism` | 红细胞内血红蛋白与葡萄糖不可逆结合的产物，反映过去 2~3 个月平均血糖水平，不受单次饮食影响 |
| `↑ causes` | 长期血糖控制不佳、妊娠糖尿病、某些血红蛋白病干扰测定 |
| `↓ causes` | 近期低血糖事件、溶血性贫血、失血、血红蛋白病、近期输血 |
| `combos` | 与空腹血糖组合评估长期控制；HbA1c 不可靠时需用果糖胺或连续血糖监测辅助 |
| `suggest` | 糖尿病患者每 3 个月复查；用于糖尿病筛查时需实验室标准化检测 |

### 4.3 餐后 2 小时血糖 2hPG

| 字段 | 内容 |
|------|------|
| `ref` | <7.8 mmol/L；≥11.1 mmol/L 需排查糖尿病 |
| `mechanism` | 反映进食后胰岛 β 细胞的胰岛素分泌储备能力 |
| `↑ causes` | 糖耐量受损、糖尿病、妊娠糖尿病、急性应激 |
| `combos` | 用于 OGTT 与糖尿病前期筛查，与空腹血糖互补 |

### 4.4 总胆固醇 TC

| 字段 | 内容 |
|------|------|
| `ref` | 合适 <5.2 mmol/L；边缘升高 5.2~<6.2；升高 ≥6.2|
| `mechanism` | 血液中各类胆固醇总和，是动脉粥样硬化风险评估的组成部分 |
| `↑ causes` | 高脂高胆固醇饮食、肥胖、糖尿病、肾病综合征、甲减、胆道梗阻、遗传性与部分药物 |
| `↓ causes` | 营养不良、甲亢、慢性消耗性疾病、严重肝病、贫血 |
| `suggest` | 与 LDL-C、HDL-C、TG 组合分层心血管风险，而非单独解读 |

### 4.5 甘油三酯 TG

| 字段 | 内容 |
|------|------|
| `ref` | 合适 <1.7 mmol/L；边缘升高 1.7~<2.3；升高 ≥2.3|
| `mechanism` | 外源性（食物）与内源性（肝脏合成）脂质，受近期饮食影响极大 |
| `↑ causes` | 肥胖、酗酒、高脂/高糖饮食、糖尿病、肾病综合征、甲减、妊娠、口服避孕药、遗传因素 |
| `↓ causes` | 吸收不良、营养不良、甲亢、慢性肝病 |
| `combos` | 明显升高（尤其 >5.6 mmol/L）需警惕急性胰腺炎风险；受空腹状态影响大 |
| `suggest` | 采血前严格空腹 8~12 小时并禁酒，复查确认；伴腹痛时急诊排查胰腺炎 |

### 4.6 低密度脂蛋白胆固醇 LDL-C

| 字段 | 内容 |
|------|------|
| `ref` | 理想 <2.6；合适 <3.4；边缘升高 3.4~<4.1；升高 ≥4.1 mmol/L |
| `mechanism` | 将胆固醇转运至血管壁的内皮下层，是动脉粥样硬化与心血管事件的"坏胆固醇" |
| `↑ causes` | 高脂饮食、肥胖、糖尿病、肾病综合征、甲减、慢性肾衰、遗传因素 |
| `↓ causes` | 营养不良、贫血、严重肝病、减重与运动 |
| `combos` | 高危人群（冠心病、糖尿病、脑卒中）目标值更严格，需按风险分层而非只看参考上限 |
| `suggest` | 异常需结合 10 年心血管风险评估，由心内科/内分泌科制定降脂目标 |

### 4.7 高密度脂蛋白胆固醇 HDL-C

| 字段 | 内容 |
|------|------|
| `ref` | 男 1.03~1.55；女 1.14~1.91 mmol/L（部分口径 <1.04 为降低） |
| `mechanism` | 将血管壁胆固醇转运回肝脏代谢，具抗动脉粥样硬化作用，"好胆固醇" |
| `↑ causes` | 规律运动、适量饮酒、遗传因素；单纯升高多无病理意义 |
| `↓ causes` | 吸烟、肥胖、糖尿病、高脂饮食、代谢综合征、肝病 |
| `combos` | 与 LDL-C、TC、TG 共同构成血脂谱；偏低提示心血管保护减弱 |
| `suggest` | 优先生活方式干预；不可单纯追求升高 |

### 4.8 脂蛋白(a) Lp(a)

| 字段 | 内容 |
|------|------|
| `ref` | <300 mg/L（不同方法学区间不同） |
| `mechanism` | 与 LDL 结构类似并含载脂蛋白(a)，水平主要由遗传决定，是独立心血管风险因子 |
| `↑ causes` | 遗传因素、家族性高胆固醇血症、家族早发心血管病史 |
| `suggest` | 升高者需强化其他危险因素管理，并筛查一级亲属 |

## 五、电解质与酸碱平衡

### 5.1 钾 K⁺

| 字段 | 内容 |
|------|------|

| `warn` | 明显高钙可致肾结石、意识模糊、心律失常，需尽快就医 |

## 十一、贫血分型与铁代谢（深化）

### 11.1 贫血分级与判定阈值

| 字段 | 内容 |
|------|------|
| `ref` | 成年男性 HGB<120 g/L、成年女性 HGB<110 g/L 可诊断贫血；孕妇<100 g/L。轻度 90~正常值下限；中度 60~90；重度 30~60；极重度<30 g/L |
| `mechanism` | 贫血是症状而非独立疾病，必须由病因分类驱动治疗，单纯"补铁"可能掩盖地贫、溶血或血液系统肿瘤 |
| `↑ causes` | 不适用；红细胞增多症见 1.6 |
| `↓ causes` | 按机制分为：生成减少（缺铁、叶酸/B12 缺乏、慢性病贫血、骨髓衰竭/浸润、肾性贫血）；破坏过多（溶血）；丢失（急慢性失血） |
| `combos` | 与 MCV 组合形成"小细胞/正细胞/大细胞"分型；与网织红细胞计数判断骨髓代偿能力；与胆红素/LDH/结合珠蛋白判断溶血 |
| `suggest` | 降低超轻度或伴乏力苍白时查血液科；先查铁代谢+叶酸/B12+网织红细胞+胆红素，不可直接补铁 |
| `warn` | 铁蛋白 400 μg/L 以上提示铁过载可能；铁蛋白显著升高伴肝功异常需排查血色病与肝病 |

### 11.2 血清铁 SI

| 字段 | 内容 |
|------|------|
| `ref` | 男 11~30 μmol/L；女 9~27 μmol/L |
| `mechanism` | 反映抽血时循环中运输铁浓度，日内波动大（晨高晚低），只代表瞬时状态，不能代表总铁储备 |
| `↑ causes` | 肝病、铁粒幼细胞贫血、再障、慢性溶血、巨幼细胞贫血、酗酒、反复输血 |
| `↓ causes` | 缺铁性贫血、感染、肾病综合征、慢性失血、妊娠与生长期铁需求增加 |
| `combos` | 须与铁蛋白、TIBC、TSAT 联合；SI 低不等于缺铁 |
| `warn` | 标本溶血、玻璃容器、EDTA 抗凝均可影响结果 |

### 11.3 转铁蛋白饱和度 TSAT / 不饱和铁结合力 UIBC

| 字段 | 内容 |
|------|------|
| `ref` | TSAT 20%~50%；<16%~20% 提示铁利用障碍 |
| `mechanism` | SI 占 TIBC 的百分比，反映可利用铁比例 |
| `↑ causes` | >45%~50% 提示铁粒幼细胞贫血或反复输血所致铁过载 |
| `↓ causes` | 缺铁性贫血、炎症性贫血 |
| `combos` | TSAT<16% 支持缺铁；>50% 需排查铁过载；是鉴别缺铁与慢性病贫血的关键 |

### 11.4 总铁结合力 TIBC / 血清转铁蛋白 sTf

| 字段 | 内容 |
|------|------|
| `ref` | 男 50~77 μmol/L；女 54~77 μmol/L；sTf 28.6~51.9 μmol/L |
| `mechanism` | 间接反映转铁蛋白总量，与 SI 联合判读价值大于单独检测 |
| `↑ causes` | 缺铁性贫血（代偿性合成增多）、红细胞增多症、口服避孕药、妊娠期 |
| `↓ causes` | 肝硬化、遗传性转铁蛋白缺乏、慢性肾病/尿毒症、慢性感染、恶性肿瘤、溶血性贫血 |
| `combos` | 缺铁：SI↓+TIBC↑；慢性病贫血：SI↓+TIBC↓；铁粒幼细胞贫血：SI↑+TSAT↑ |

### 11.5 叶酸 / 维生素 B12

| 字段 | 内容 |
|------|------|
| `ref` | 血清叶酸 5.3~14.4 μg/L；RBC 叶酸 192~577 μg/L；维生素 B12 133~675 pmol/L |
| `mechanism` | 两者均为 DNA 合成必需辅酶，缺乏导致红细胞核发育障碍→大细胞性贫血 |
| `↑ causes` | B12 升高见于白血病、真性红细胞增多症、部分恶性肿瘤、肝细胞损伤 |
| `↓ causes` | 叶酸缺乏：摄入不足、吸收不良（乳糜泻、小肠切除）、药物（甲氨蝶呤、抗癫痫药）、利用增加（溶血、甲亢、恶性肿瘤）；B12 缺乏：恶性贫血（内因子抗体）、胃切除、吸收不良、素食 |
| `combos` | MCV 升高+叶酸/B12 降低→巨幼细胞贫血；B12 缺乏可伴舌炎、手脚麻木等神经症状 |
| `suggest` | 降低者需查明吸收障碍原因，长期用药者监测并调整 |

### 11.6 网织红细胞计数 Ret-He / Ret%

| 字段 | 内容 |
|------|------|
| `ref` | 0.5%~1.5%（绝对值 24~84×10⁹/L，各平台差异） |
| `mechanism` | 骨髓刚释放的未成熟红细胞，直接反映骨髓造血代偿能力与补铁/补 B12 后的治疗反应 |
| `↑ causes` | 溶血性贫血、急性失血后代偿、缺铁性贫血/巨幼细胞贫血治疗有效后（"补铁后跃升"） |
| `↓ causes` | 再生障碍性贫血、骨髓浸润、肾性贫血、慢性病贫血、治疗后骨髓抑制 |
| `combos` | 贫血伴网织升高→溶血或失血；贫血伴网织降低→生成障碍；Ret-He 低提示功能性缺铁 |

### 11.7 促红细胞生成素 EPO

| 字段 | 内容 |
|------|------|
| `ref` | 4~26 IU/L（缺氧时生理性升高，无固定上限） |
| `mechanism` | 肾脏分泌，刺激骨髓红系造血；肾性贫血时相对不足 |
| `↑ causes` | 缺铁、地贫、溶血、慢性缺氧、肾癌、肝癌 |
| `↓ causes` | 肾衰竭、晚期肾病、慢性感染、类风湿关节炎、营养不良、部分内分泌性贫血 |
| `combos` | EPO 不升反降伴贫血→肾性/内分泌性/骨髓反应不良；是鉴别肾性贫血与骨髓造血障碍的重要依据 |

### 11.8 内因子抗体 IFBA

| 字段 | 内容 |
|------|------|
| `ref` | 阴性（平台差异大） |
| `mechanism` | 阻断内因子与 B12 结合，导致 B12 吸收障碍（恶性贫血） |
| `↑ causes` | 恶性贫血、部分萎缩性胃炎、自身免疫性甲状腺病 |
| `suggest` | 阳性伴 B12 缺乏需消化内科/血液科评估，警惕自身免疫性多腺体综合征 |

### 11.9 贫血鉴别铁代谢矩阵

| 类型 | SI | 铁蛋白 | TIBC | TSAT | 铁代谢特征 |
|------|----|--------|------|------|------------|
| 缺铁性贫血 | ↓ | ↓ | ↑ | ↓ | 储存与运输铁均减少 |
| 慢性病贫血 | ↓/正常 | ↑/正常 | ↓/正常 | ↓ | 储存铁高、利用障碍 |
| 铁粒幼细胞贫血 | ↑ | ↑ | — | >45% | 铁利用障碍、铁过载 |
| 溶血/巨幼 | ↑ | ↑ | — | 正常/↑ | 无效造血、铁释放 |

## 十二、胰腺与消化相关酶学

### 12.1 淀粉酶 AMY

| 字段 | 内容 |
|------|------|
| `ref` | 血 35~135 U/L；尿<1000 U/L |
| `mechanism` | 主要来源于胰腺与腮腺；胰腺/腮腺病变时血淀粉酶升高早、持续时间短，尿淀粉酶升高晚、持续时间长 |
| `↑ causes` | 急性胰腺炎、慢性胰腺炎急性发作、胰腺癌、胰管梗阻；非胰腺：腮腺炎、消化性溃疡穿孔、肠梗阻/绞窄、胆结石/胆囊炎、异位妊娠破裂、肾衰、阑尾炎、腹膜炎、DKA、巨淀粉酶血症、乙醇中毒 |
| `↓ causes` | 慢性胰腺炎晚期腺体纤维化、胰腺癌长期压迫、肾衰晚期、巨淀粉酶血症 |
| `combos` | 需与脂肪酶、腹 CT/超声、血常规、CRP 联合；淀粉酶升高而脂肪酶不高需考虑唾液腺来源 |
| `suggest` | 急腹痛伴升高查消化内科/急诊，必要时腹部增强 CT |
| `warn` | 淀粉酶正常不能排除胰腺炎；轻度肾功改变即影响尿淀粉酶准确性，尿淀粉酶临床价值有限 |

### 12.2 脂肪酶 LPS

| 字段 | 内容 |
|------|------|
| `ref` | 偶联法 1~54 U/L；色原底物法 13~63 U/L |
| `mechanism` | 主要来自胰腺，胰腺损伤或胰管梗阻时释放入血，升高晚于淀粉酶但持续更久（起病 24~72 小时升高、持续 7~10 天） |
| `↑ causes` | 急性胰腺炎、胰管梗阻、胰腺肿瘤；中度升高也可见于肾衰、唾液腺炎、肠梗阻、胃溃疡、肝炎肝硬化、酗酒 |
| `↓ causes` | 胰腺分泌细胞永久性损伤、胰腺癌导管阻塞、儿童囊性纤维化 |
| `combos` | 与淀粉酶联合诊断急性胰腺炎，特异性与敏感性略优；与 CRP 联合判断胰腺坏死（72 小时 CRP>150 mg/L 提示坏死） |
| `suggest` | 升高不必然等于胰腺炎，需结合腹痛特征与影像 |
| `warn` | 甘油三酯过高可"掩盖"淀粉酶不升高，所有胰腺炎疑似者须查 TG |

### 12.3 血清脂肪酶/淀粉酶动态判读

| 字段 | 内容 |
|------|------|
| `ref` | 血淀粉酶起病后 2~12 小时升高、48 小时开始下降、持续 3~5 天 |
| `mechanism` | 时间窗差异决定了"就诊晚的患者"脂肪酶更有诊断价值 |
| `↑ causes` | 延误就诊者淀粉酶可能已回落而脂肪酶仍高 |
| `combos` | 起病 24 小时内以淀粉酶为主；24~72 小时后脂肪酶更可靠；两者均正常基本可排除急性胰腺炎 |

### 12.4 血脂异常相关胰腺风险

| 字段 | 内容 |
|------|------|
| `mechanism` | TG>11.3 mmol/L 是急性胰腺炎的高危阈值，是高脂血症性胰腺炎的核心机制 |
| `↑ causes` | 肥胖、糖尿病、酗酒、肾病综合征、妊娠、家族性高甘油三酯血症 |
| `combos` | 淀粉酶不升高+高 TG→高脂血症性胰腺炎；是病因诊断的必需组合 |
| `suggest` | TG 明显升高需降脂并排查胰腺风险，查内分泌科/消化内科 |

### 12.5 胃蛋白酶原 PGⅠ / PGⅡ 与胃泌素-17

| 字段 | 内容 |
|------|------|
| `ref` | PGⅠ 70~165 μg/L；PGⅡ 3~15 μg/L；PGⅠ/PGⅡ 比值>3.0；胃泌素-17 1.0~15.0 pmol/L（各平台差异大） |
| `mechanism` | 反映胃黏膜萎缩与胃酸分泌状态，用于胃癌风险分层 |
| `↑ causes` | PGⅡ 升高伴比值下降→萎缩性胃炎/肠化倾向；胃泌素-17 升高→胃体萎缩或胃酸缺乏 |
| `combos` | 低 PGⅠ + 低比值 + 高胃泌素-17 是胃癌筛查高风险组合 |
| `suggest` | 异常需结合胃镜与幽门螺杆菌检测 |

### 12.6 幽门螺杆菌抗体 / 尿素酶呼气试验

| 字段 | 内容 |
|------|------|
| `ref` | 阴性 |
| `mechanism` | 反映 Hp 现症感染（呼气试验）或既往/现症感染（抗体，治疗后可长期阳性） |
| `↑ causes` | Hp 感染，与慢性胃炎、消化性溃疡、胃黏膜相关淋巴组织淋巴瘤、胃癌风险相关 |
| `suggest` | 阳性者根除治疗需规范用药，治疗后 4 周复查确认，不可仅凭抗体判断根除成功 |

## 十三、血气分析与酸碱平衡

### 13.1 pH

| 字段 | 内容 |
|------|------|
| `ref` | 7.35~7.45 |
| `mechanism` | 体液酸碱度，决定酶活性与电解质分布；代偿可使其维持正常 |
| `↑ causes` | 失代偿性碱中毒（碱血症）  |
| `↓ causes` | 失代偿性酸中毒（酸血症） |
| `combos` | pH 正常不能排除酸碱失衡，可见于代偿性或混合性酸碱失衡 |
| `warn` | 判读必须以动脉血为准，静脉血结果无效 |

### 13.2 动脉血氧分压 PaO₂

| 字段 | 内容 |
|------|------|
| `ref` | 80~100 mmHg（随年龄下降，实用上以 80 mmHg 以上为参考） |
| `mechanism` | 物理溶解于动脉血中的氧分子产生的压力，反映肺换气与氧供 |
| `↑ causes` | 过度通气、吸入高浓度氧 |
| `↓ causes` | 呼吸衰竭、肺部疾病、贫血、低通气、通气血流比失调、弥散障碍、分流 |
| `combos` | 低氧血症分级：80~60 轻度、60~40 中度、<40 重度；PaO₂<60 mmHg 可诊断呼吸衰竭（排除心内分流等） |

### 13.3 肺泡-动脉氧分压差 A-aDO₂ / P/F 比

| 字段 | 内容 |
|------|------|
| `ref` | A-aDO₂<10 mmHg 正常，10~20 边界，>20 异常；P/F 比<300 提示 ALI，<200 提示 ARDS |
| `mechanism` | 区分低氧是单纯肺泡低通气还是存在换气障碍/分流 |
| `↑ causes` | 分流、通气血流比不均、弥散障碍；纯低通气时 A-aDO₂ 不增大 |
| `combos` | A-aDO₂ 增大+氧疗反应差→高度提示分流存在 |

### 13.4 动脉血二氧化碳分压 PaCO₂

| 字段 | 内容 |
|------|------|
| `ref` | 35~45 mmHg |
| `mechanism` | 反映肺泡通气量，与通气量成反比；呼吸因素的核心指标 |
| `↑ causes` | 通气不足→呼吸性酸中毒：COPD、哮喘、镇静剂过量、呼吸肌疲劳、CNS 抑制 |
| `↓ causes` | 通气过度→呼吸性碱中毒或代谢性酸中毒的肺代偿：脑外伤、休克、DKA、癔症、发热 |
| `combos` | 与 HCO₃⁻ 组合确定原发因素；呼酸时肾代偿需 3~5 天达最大 |

### 13.5 碳酸氢根 HCO₃⁻（实际 AB / 标准 SB）

| 字段 | 内容 |
|------|------|
| `ref` | AB 与 SB 均为 22~27 mmol/L，均值 24 |
| `mechanism` | 代谢因素的核心指标，主要受肾脏调节 |
| `↑ causes` | 代谢性碱中毒或呼吸性酸中毒代偿：呕吐、胃液引流、利尿剂、低钾、慢性高碳酸血症 |
| `↓ causes` | 代谢性酸中毒或呼吸性碱中毒代偿 |
| `combos` | AB=SB 正常→代谢性碱中毒；AB>SB→呼吸性酸中毒；AB<SB→呼吸性碱中毒 |

### 13.6 碱剩余 BE

| 字段 | 内容 |
|------|------|
| `ref` | -2.3~+2.3 mmol/L（部分口径 -3~+3） |
| `mechanism` | 全血在标准条件下滴定至 pH 7.40 所需的酸或碱量，反映非呼吸性酸碱失衡程度 |
| `↑ causes` | >+2.3 提示代谢性碱中毒 |
| `↓ causes` | <-2.3 提示代谢性酸中毒 |
| `combos` | 与 AG 联合对代谢性酸中毒分型 |

### 13.7 阴离子间隙 AG

| 字段 | 内容 |
|------|------|
| `ref` | 8~16 mmol/L；计算公式 AG=Na⁺−(Cl⁻+HCO₃⁻) |
| `mechanism` | 未测定的阴离子（乳酸、酮酸、磷酸、硫酸、蛋白）总量，是代谢性酸中毒分型的关键 |
| `↑ causes` | 高 AG 正常血氯性代谢性酸中毒：乳酸酸中毒、酮症酸中毒、尿毒症、中毒（甲醇、乙二醇、水杨酸） |
| `↓ causes` | 低白蛋白血症可致假性降低，需校正 |
| `combos` | 正常 AG 代谢性酸中毒→腹泻、肾小管酸中毒、Addison 病、大量输注生理盐水 |

### 13.8 血气判读六步法

| 步骤 | 判读内容 |
|------|----------|
| 1 | 确认标本为动脉血且质量合格 |
| 2 | 看 pH 判断酸血症/碱血症/正常范围 |
| 3 | 看 PaCO₂ 与 HCO₃⁻ 确定原发是呼吸性还是代谢性 |
| 4 | 用预计代偿公式判断是否为单纯性或存在混合性失衡 |
| 5 | 计算 AG 对代谢性酸中毒分型 |
| 6 | 结合电解质、血糖、乳酸、酮体、肾功能与临床场景定因 |

### 13.9 常见酸碱紊乱速查

| 原发紊乱 | pH | PaCO₂ | HCO₃⁻ | 常见原因 |
|----------|----|-------|-------|----------|
| 代谢性酸中毒 | ↓ | ↓（代偿） | ↓↓ | DKA、乳酸酸中毒、肾衰、腹泻 |
| 代谢性碱中毒 | ↑ | ↑（代偿） | ↑↑ | 呕吐、利尿剂、低钾 |
| 呼吸性酸中毒 | ↓ | ↑↑ | ↑（代偿） | COPD、镇静过量、呼吸肌疲劳 |
| 呼吸性碱中毒 | ↑ | ↓↓ | ↓（代偿） | 焦虑通气过度、发热、休克早期 |

## 十四、免疫球蛋白与补体

### 14.1 免疫球蛋白 G IgG

| 字段 | 内容 |
|------|------|
| `ref` | 8~16 g/L（平台差异大） |
| `mechanism` | 血清含量最高的免疫球蛋白，唯一能通过胎盘，反映既往/持续免疫刺激与体液免疫储备 |
| `↑ causes` | 慢性肝病、结缔组织病、慢性感染、单克隆增殖（需警惕多发性骨髓瘤） |
| `↓ causes` | 蛋白丢失性肠病、肾病综合征、混合性免疫缺陷、遗传性或获得性抗体缺乏 |
| `combos` | IgG 显著升高而 IgA/IgM 低、伴总蛋白升高与白球比倒置→需排查多发性骨髓瘤，建议蛋白电泳/免疫固定电泳 |

### 14.2 免疫球蛋白 A IgA

| 字段 | 内容 |
|------|------|
| `ref` | 0.7~4.0 g/L |

| `combos` | 维生素 D 缺乏+继发性甲旁亢+低钙/高磷倾向→需补充并复查 PTH 与钙磷 |

### 16.10 性激素六项（FSH / LH / E2 / P / T / PRL）

| 字段 | 内容 |
|------|------|
| `ref` | 各项均随性别与女性月经周期/绝经状态大幅变化，必须标注周期日并采用实验室对应区间 |
| `mechanism` | 下丘脑-垂体-性腺轴，受年龄、应激、泌乳、药物、采血时间影响极大 |

| `↓ causes` | 垂体功能减退、性腺功能减退、低促性腺激素性闭经 |
| `combos` | 判读必须结合采血时相（女性按周期日）、上午 8~10 时采血、排除应激与泌乳刺激 |
| `warn` | 单次性激素结果参考价值有限，常需复查或做促性腺激素释放激素兴奋试验 |

### 16.11 抗苗勒管激素 AMH

| 字段 | 内容 |
|------|------|
| `ref` | 随年龄变化：20~24 岁约 4.0~10.0 ng/mL，35 岁后下降，>40 岁常<1.0 ng/mL（平台差异大） |

### 16.12 甲状腺功能深化（FT4/FT3/TSH 以外）

## 十七、骨代谢与心肌酶深化

### 17.1 乳酸脱氢酶 LDH 与同工酶

| 字段 | 内容 |
|------|------|
| `ref` | 总 LDH 120~250 U/L；同工酶：LDH1 24%~34%，LDH2 35%~44%，LDH3 19%~27%，LDH4 0%~5%，LDH5 0%~2% |
| `mechanism` | 广泛存在于心、肝、骨骼肌、红细胞、肾、肺等组织，特异性低，主要用于提示组织破坏部位 |
| `↑ causes` | 溶血、心肌梗死、肝病、肺栓塞、恶性肿瘤、肾梗死、肌肉损伤、溶血标本 |

### 17.2 碱性磷酸酶同工酶

| 字段 | 内容 |
|------|------|
| `mechanism` | ALP 含肝型、骨型、肠型、胎盘型、肾型，电泳或热灭活可区分来源 |
| `↑ causes` | 肝型升高→肝胆疾病；骨型升高→骨代谢活跃（Paget 病、骨软化、骨转移、儿童生长）；胎盘型→妊娠 |
| `combos` | GGT 正常+ALP 升高时做同工酶，鉴别肝胆源性（GGT 同步升）与骨源性（仅骨型升） |

### 17.3 钙磷代谢深化

| 字段 | 内容 |
|------|------|
| `ref` | 校正钙=总钙+0.02×(40−白蛋白)，单位 g/L |
| `mechanism` | 约 40% 钙与白蛋白结合，低白蛋白时总钙假性降低 |
| `↑ causes` | 未校正的低白蛋白→假性低钙；校正后真性高钙需排查甲旁亢、恶性肿瘤 |
| `combos` | 低白蛋白血症患者必须以校正钙或离子钙判读；慢性肾病典型表现：高磷、低钙、继发性甲旁亢 |

| `combos` | 骨形成与骨吸收指标同步升高→高转换状态；用于抗骨吸收治疗（双膦酸盐）的疗效监测 |

## 十八、早期肾损伤与尿蛋白系列

### 18.1 尿微量白蛋白/肌酐比值 UACR 与 24 小时尿蛋白定量

| 字段 | 内容 |
|------|------|
| `ref` | UACR 正常值<30 mg/g；30~300 mg/g 为微量白蛋白尿；>300 mg/g 为大量白蛋白尿。24h 尿蛋白<150 mg/24h 正常，0.15~0.5 g 轻度、0.5~3.5 g 中度、>3.5 g 肾病范围 |
| `mechanism` | 肾小球滤过屏障受损的早期信号，早于尿常规蛋白定性阳性 |
| `↑ causes` | 糖尿病肾病、高血压肾损害、肾小球肾炎、子痫前期；剧烈运动、发热、感染可一过性升高 |
| `combos` | UACR 是糖尿病/高血压肾损害的筛查金标准；需清晨第一次尿或随机尿标本 |
| `suggest` | 糖尿病、高血压患者每年至少筛查 1 次 |
| `warn` | 月经期、剧烈运动后 24 小时、发热感染期可假性升高，需择期复查 |

### 18.2 尿 N-乙酰-β-D-氨基葡萄糖苷酶 NAG

| 字段 | 内容 |
|------|------|
| `ref` | <17 U/L（各实验室不同） |
| `mechanism` | 存在于肾小管上皮细胞溶酶体，尿中升高反映肾小管损伤 |
| `↑ causes` | 药物性肾损伤（氨基糖苷类、顺铂）、重金属、缺血、糖尿病肾病早期、肾盂肾炎 |
| `combos` | 与 UACR 组合：NAG↑而白蛋白正常→以肾小管损伤为主；两者均↑→混合性肾损伤 |

### 18.3 α1-微球蛋白 / β2-微球蛋白（尿）

| 字段 | 内容 |
|------|------|
| `ref` | α1-MG 尿<12 mg/L；β2-MG 尿<0.2 mg/L |
| `mechanism` | 小分子蛋白，经肾小球自由滤过，由近曲小管重吸收；尿中升高提示肾小管重吸收障碍 |
| `↑ causes` | 肾小管间质病变、药物性肾毒性、重金属中毒、范可尼综合征、肾盂肾炎 |
| `combos` | 与血清 β2-MG 联合鉴别：尿升而血不高→肾小管重吸收障碍；血与尿均升→肾小球滤过下降 |

### 18.4 视黄醇结合蛋白 RBP / 胱抑素 C 深化

| 字段 | 内容 |
|------|------|
| `mechanism` | RBP 与胱抑素 C 均为小分子蛋白，肾小球滤过受损时升高；较肌酐更早反映 GFR 下降 |
| `combos` | 胱抑素 C 受肌肉量、年龄、性别影响小，适合老年、肌少症、截肢人群 |

### 18.5 尿电解质与渗透压

|------|------|
| `ref` | 尿钠 40~220 mmol/24h；尿钾 25~125 mmol/24h；尿渗透压 600~1000 mOsm/kg（晨尿可达 800~1400） |

## 十九、其他常用指标

### 19.1 同型半胱氨酸 Hcy

| 字段 | 内容 |
|------|------|
| `ref` | <10 μmol/L 为诊断阈值；10~15 轻度、15~30 中度、>30 重度高同型半胱氨酸血症 |
| `mechanism` | 甲硫氨酸代谢中间产物，通过损伤内皮、氧化应激、脂质代谢异常与促血栓机制增加心脑血管风险 |
| `↑ causes` | 叶酸/B6/B12 缺乏、MTHFR 基因突变（中国人群频率高）、慢性肾病、甲减、年龄增长、吸烟饮酒、药物（甲氨蝶呤、抗癫痫药、利尿剂） |
| `combos` | 与高血压组合定义为 H 型高血压（中国高血压患者中约 75% 伴 Hcy 升高）；与血脂、血糖同为心血管风险评估指标 |
| `suggest` | 升高需查叶酸、B12 并调整生活方式，心内科/神经内科评估风险 |
| `warn` | 检查前需空腹 6 小时、避免剧烈运动与熬夜，妊娠时 Hcy 生理性降低 |

### 19.2 氨基末端脑钠肽前体 NT-proBNP 深化

| 字段 | 内容 |
|------|------|
| `ref` | 排除急性心衰：<300 pg/mL；年龄<50 岁<450、50~75 岁<900、>75 岁<1800 pg/mL（各指南与平台差异大） |
| `mechanism` | 心室壁张力增高时分泌，半衰期长于 BNP，更稳定 |
| `↑ causes` | 心衰、ACS、房颤、肺栓塞、高龄、肾功能不全、脓毒症 |
| `combos` | 年龄分层判读；与 ECG、胸片、超声心动图、肾功能联合 |

### 19.3 心肌肌钙蛋白 T/I 高敏化判读深化

| 字段 | 内容 |
|------|------|
| `mechanism` | 第 99 百分位上限为诊断临界值，不同平台不能横向比较 |
| `↑ causes` | 非冠脉原因：心衰、心肌炎、肺栓塞、严重脓毒症、肾功能不全、快速性心律失常、剧烈运动 |
| `combos` | 0h/1h 或 0h/3h 动态变化曲线是排除与诊断的核心；仅绝对值不能定因 |

### 19.4 D-二聚体临床概率整合

| 字段 | 内容 |
|------|------|
| `mechanism` | 阴性预测价值高于阳性预测价值，适合用于排除而非确诊 |
| `↑ causes` | VTE、DIC、恶性肿瘤、脓毒症、术后、创伤、妊娠、高龄、慢性肝病 |

### 19.5 红细胞沉降率深化

| 字段 | 内容 |
|------|------|
| `mechanism` | 受纤维蛋白原、球蛋白、红细胞数量与形态共同影响，变化滞后于急性炎症 |

### 19.6 抗链球菌溶血素 O ASO

|------|------|

## 附录 A：常见组合判读模式

### A.1 常规模式速查

| 模式 | 指标组合特征 | 优先排查方向 |
|------|--------------|--------------|
| 细菌感染/炎症 | WBC↑+中性粒↑+CRP↑+PCT↑ | 细菌感染；病毒或非感染性炎症时 PCT 多不高 |
| 肝细胞损伤型 | ALT/AST↑↑ 且明显大于 ALP | 脂肪肝、病毒性肝炎、药物性肝损伤、酒精性肝病、AIH |
| 胆汁淤积型 | ALP↑ 且明显大于 ALT/AST，GGT 同步↑ | 结石/肿瘤梗阻、PBC、PSC、药物性胆汁淤积 |
| 混合性损伤 | ALT/AST 与 ALP 均升高 | 各类肝病进展期或合并胆汁淤积 |
| 孤立胆红素升高 | TBIL↑，转氨酶与 ALP/GGT 正常 | Gilbert 综合征、溶血、其他先天代谢异常 |
| 肾小球疾病 | 蛋白尿+血尿+变形红细胞+管型 | 各类肾炎、糖尿病/高血压肾损害 |
| 泌尿系感染 | LEU+/NIT+，伴白细胞增多 | 膀胱炎、肾盂肾炎 |
| 急性胰腺炎 | 淀粉酶与脂肪酶↑↑+上腹痛 | 胆源性、酒精性、高脂血症性；查腹部 CT 与 TG |
| 急性冠脉综合征 | 肌钙蛋白动态↑+ECG 改变+症状 | 心梗，需急诊 |
| 甲状腺轴 | TSH↓/↑ 与 FT4 反向 | 原发于甲状腺的甲亢/甲减；同向需查垂体轴 |
| 肾前性氮质血症 | BUN/Cr 比值升高，尿常规相对正常 | 脱水、低血容量、高分解状态 |
| 缺铁性贫血 | 小细胞低色素+SI↓+铁蛋白↓+TIBC↑+TSAT↓ | 缺铁；须排查消化道/妇科慢性失血 |
| 慢性病贫血 | 正细胞贫血+铁蛋白正常或↑+TIBC↓+TSAT↓ | 炎症/肿瘤/感染；治原发病 |
| 巨幼细胞贫血 | 大细胞+MCH↑+叶酸或 B12↓ | 营养缺乏、吸收不良、恶性贫血 |
| 铁过载 | 铁蛋白显著↑（>1000）+TSAT>50% | 遗传性血色病、反复输血；查转铁蛋白饱和度与肝铁 |
| 溶血 | 间接胆红素↑+LDH↑+结合珠蛋白↓+网织↑ | 溶血性贫血；查 Coombs、G6PD、血红蛋白电泳 |
| 高阴离子间隙代谢性酸中毒 | AG↑+HCO₃⁻↓ | DKA、乳酸酸中毒、尿毒症、中毒 |
| 正常阴离子间隙代谢性酸中毒 | AG 正常+HCO₃⁻↓ | 腹泻、肾小管酸中毒、大量生理盐水输注 |
| 呼吸性酸中毒 | pH↓+PaCO₂↑↑ | COPD、镇静过量、呼吸肌疲劳 |
| 呼吸性碱中毒 | pH↑+PaCO₂↓↓ | 焦虑通气过度、发热、休克早期、肺栓塞 |
| 低氧血症 | PaO₂<80 或 SaO₂<90 | 肺疾病、贫血、通气/换气障碍；计算 A-aDO₂ 与 P/F 比 |
| 系统性红斑狼疮活动 | ANA/抗 dsDNA/抗 Sm 阳性+补体 C3/C4 下降 | SLE 活动期；查肾损害与血液系统受累 |
| 多发性骨髓瘤信号 | IgG 显著↑+IgA/IgM↓+总蛋白↑+白球比倒置 | 血清蛋白电泳/免疫固定电泳/尿本周蛋白；转血液科 |
| 子痫前期风险 | 高血压+UACR↑/尿蛋白↑+尿酸↑ | 妊娠 20 周后；产科评估 |

### A.2 多指标矛盾时的判读优先级

1. **动态变化 > 单次绝对值**：肌钙蛋白、淀粉酶、PCT、CRP、肿瘤标志物均需前后对照。
2. **游离型 > 总激素**：T4/T3 与钙在结合蛋白异常时以 FT4/FT3、离子钙为准。
3. **组合逻辑 > 单项箭头**：孤立箭头多无病理意义，组合模式才指向病因。
4. **临床场景 > 参考区间**：急症症状优先于数值解读；参考区间只回答"是否偏离常态"。
5. **报告单参考区间 > 本文档区间**：实验室、方法、年龄性别差异必须服从受检者报告单。

## 附录 B：干扰因素与注意事项

### B.1 标本质量

- 溶血影响钾、ALT、AST、LDH、肌红蛋白、血清铁；网织红细胞计数与 LD​​H 同工酶判读尤需警惕溶血。
- 脂血影响比色法与光散射法项目；高胆红素血症可干扰部分免疫比浊项目。
- 标本放置过久影响血糖（糖酵解）、乳酸、血气、胆红素、尿有形成分与管型。
- 尿液必须清洁中段尿，避免月经血、阴道分泌物、精液污染；24 小时尿需准确计时与防腐。

### B.2 饮食与用药

- 血脂、血糖、铁代谢需空腹；淀粉酶、脂肪酶需禁食并禁酒 8~12 小时。
- 他汀影响 CK；抗生素、抗癫痫药、避孕药可影响肝酶与铁代谢。
- 利尿剂影响电解质；ACEI/ARB/螺内酯影响血钾；糖皮质激素影响血糖与淋巴细胞。
- 生物素干扰链霉亲和素-生物素免疫法检测（含部分 TSH、FT4、肌钙蛋白、叶酸/B12），采血前需停药。
- 秋水仙碱及灵芝孢子粉、螺旋藻、金蝉花等滋补品可致 CA72-4 假性升高。

### B.3 生理与病理状态

- 妊娠：铁蛋白下降、D-二聚体升高、eGFR 改变、ALP 升高、甲功区间不同，均须专用标准。
- 儿童与青少年：ALP 生理性升高；老年人参考区间与疾病谱不同；运动员肌酸激酶基线偏高。
- 月经周期、剧烈运动、脱水、高原、应激、吸烟、饮酒均会改变多项指标。
- 肾小球滤过率随年龄下降属生理性；肌少症者肌酐偏低可能掩盖肾功能减退。

### B.4 平台与方法学差异

- 不同检测平台结果不可直接横向比较：肌钙蛋白、性激素、甲状腺激素、肿瘤标志物、血气、免疫球蛋白尤为突出。
- 复查应尽量在同一实验室进行；更换平台时注明方法学差异。
- 尿试纸项目（潜血、蛋白、糖、酮体、白细胞酯酶、亚硝酸盐）灵敏度与特异性均有限，阳性需镜检或定量复核。

## 附录 E：知识库维护规范（面向工程化使用）

### E.1 字段完整性约束

- 每条指标必须包含 `ref` 与 `mechanism` 字段；缺项意味着该指标不具备判读基础，应标记 `status: draft` 而非发布。
- `↑ causes` 与 `↓ causes` 至少各有一条内容或显式标注"无独立临床意义"，禁止空字段。
- `combos` 字段是知识库的核心价值所在，单指标条目若无法写出组合逻辑，应合并入上级章节或删除。

### E.2 版本与更新触发条件

- 触发更新：检验方法学变更、专科指南阈值修订、新的药物干扰证据、参考区间本地化标准发布。
- 更新记录格式：`v{主版本}.{次版本}｜日期｜变更范围｜依据来源`。

### E.3 多语言与跨地区适配

- 指标缩写存在地区差异（如 APTT/PTT、TSH/HTSH、HbA1c/GHb），建议建立 `abbr_aliases` 映射表。
- 单位换算表需独立维护（mg/dL 与 mmol/L、U/L 与 μkat/L、ng/mL 与 pmol/L）。
- 中文报告常见表述"阴性/阳性/±"需映射到数值字段以便检索。

### E.4 检索与匹配建议

- 索引键建议采用 `name + abbr + 常用别名` 三层映射，避免"谷丙转氨酶"与"丙氨酸氨基转移酶"检索遗漏。
- 参考区间应存储为 `{low, high, unit, age_range, sex, method}` 结构体，而非字符串。
- `warn` 字段应被检索系统优先返回，置于解读结论之前。
